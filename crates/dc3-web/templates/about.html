About {{ page.site_name }}

{{ page.site_name }} is a search engine for torrents that are shared through the BitTorrent distributed hash table (DHT). It runs dhtcrawler4, free software whose source anyone can read and run.

How it works

  1. A crawler takes part in the DHT as an ordinary node that answers other nodes' requests, and learns the keys (info hashes) of torrents that are being shared.
  2. For each key it asks the peers sharing that torrent for its metadata: the torrent's name and its list of files. The metadata is used only if it matches the key.
  3. Names and file lists are stored and indexed so that they can be searched by words in any language.

What this site does not do

  • It does not host, download or distribute the content of any torrent. It stores only names, file lists, sizes and dates, and shows magnet links that a BitTorrent client can use to find a torrent in the DHT.
  • It does not track you: no JavaScript, no analytics, no advertising and nothing loaded from other sites. The only cookie is an optional theme preference, set only when you use the dark/light mode switch. See the privacy page.

Searching

  • Every word must appear in the torrent's name or in one of its file names.
  • Put words in "double quotes" to find them as a phrase, and put a minus sign in front of a word (-word) to leave out torrents that contain it.
  • The last word also finds longer words that start with it, unless the search ends with a space.
  • Chinese, Japanese and Korean text can be searched by any part of a word, including single characters.

Questions: see the privacy page.
